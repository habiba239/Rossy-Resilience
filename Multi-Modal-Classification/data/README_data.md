# Data Setup — Task 2 (Multi-Modal Classification)

## Included CSV files (propensity scores & paired data)

| File | Description |
|------|-------------|
| `tabular_ft_train.csv` | Mammogram propensity scores — train split |
| `tabular_ft_val.csv` | Mammogram propensity scores — val split |
| `tabular_final_test.csv` | Mammogram propensity scores — test split |
| `train_predictions.csv` | Ultrasound CatBoost predictions — train |
| `validation_predictions.csv` | Ultrasound CatBoost predictions — val |
| `test_predictions.csv` | Ultrasound CatBoost predictions — test |
| `all_pairs.csv` | Final OT-paired dataset (1,681 pairs) |
