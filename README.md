# Breast Cancer CAD — Graduation Project

> This repository contains the work developed as part of our graduation project:  
> **"A Clinical Decision Support System (CDSS) for Breast Cancer Diagnosis"**  
> The project combines two deep learning tasks to build a comprehensive, multi-modal Computer-Aided Diagnosis pipeline.

---

## Project Overview

Breast cancer diagnosis traditionally relies on radiologists interpreting mammograms and ultrasounds in isolation. This project bridges that gap by building a two-task AI system:

- **Task 1 — Mammogram Detection & Segmentation:** Automatically locates and delineates breast masses in mammograms using a two-stage YOLO11s → U-Net pipeline.
- **Task 2 — Multi-Modal Classification:** Fuses mammogram and ultrasound predictions via Optimal Transport pairing and Late Fusion to produce a unified malignancy classification.

Together, these two tasks form the backbone of a CDSS that processes raw mammograms and ultrasounds, outputting precise lesion characteristics and a final diagnostic prediction.
